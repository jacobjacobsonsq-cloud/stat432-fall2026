Question 1: Choosing an SVM kernel

The response is coronary heart disease status (chd) for 462 observations. I used the nine requested predictors and coded famhist as 1 for Absent and 2 for Present.

Evaluation design. Using seed 43209, I shuffled observations separately within each response class and assigned them cyclically to five folds. Each fold contained 92 or 93 observations and exactly 32 CHD cases. Every candidate used these same folds. Within each split, I estimated each predictor's mean and standard deviation from the four fitting folds only, then applied those values to both fitting and validation observations. The primary metric was the unweighted misclassification rate, averaged over the five folds.

I compared exactly 20 settings. Polynomial kernels used K(u,v) = (γuTv + 1)d, with coef0 = 1 and γ = 1/9 fixed; only degree and cost varied. For the radial kernel, γ and cost varied.

Choice. The numerical minimum is radial with C = 1 and γ = 0.01 (mean error 0.2707, fold-based SE 0.0199). I prefer the linear model with C = 0.1. Its error is only 0.0066 higher and is below the one-standard-error cutoff, 0.2707 + 0.0199 = 0.2906. Thus the observed nonlinear improvement is just three of 462 out-of-fold predictions, while the linear boundary is substantially easier to interpret and less flexible.

Question 2: One-page SVM analysis report

Suitability and safeguards

This is a feasible binary SVM problem: 462 observations, nine predictors, and a 160/302 (34.6%/65.4%) class split. There are no missing values, duplicated rows, or predictors that directly encode chd. Forty-one rows have at least one predictor more than three standard deviations from its full-data mean, so soft margins and fold-specific scaling are useful; these observations were retained. No groups or time ordering were supplied. With no asymmetric error costs specified, I defined ordinary misclassification rate as the primary metric before tuning; sensitivity and specificity supplement it. I did not apply class weights because the imbalance is moderate and the target metric is unweighted error.

Models and evaluation

I considered a linear baseline, polynomial degrees 2–4 for progressively more curved boundaries, and a radial kernel for smooth local nonlinearity. I used the same reproducible, approximately stratified five folds and the 20-setting logarithmic grid reported in Question 1. Means and standard deviations were recomputed using only each split's fitting observations, preventing preprocessing leakage.

Final model and interpretation

The radial minimum improves on linear C = 0.1 by only 0.0066, and the linear result lies within one SE of the minimum. I therefore select the simpler linear SVM. Its pooled out-of-fold confusion counts are TN=257, FP=45, FN=83, TP=77: error 0.277 (accuracy 0.723), sensitivity 0.481, and specificity 0.851. The final full-data fit has 283 support vectors, indicating substantial class overlap. On the standardized scale, the largest positive boundary coefficients are family history (0.444), age (0.380), tobacco (0.341), type-A score (0.312), and LDL (0.287); obesity is negative (-0.241). These are conditional directions of the fitted boundary, not causal effects. Selection and performance use the same CV run, so 0.277 should be treated as selection evidence rather than an unbiased final-test estimate.
